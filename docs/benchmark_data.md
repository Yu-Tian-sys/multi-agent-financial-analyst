## 评估方法论

| 维度 | 方法 | 通过阈值 |
|------|------|----------|
| 财务指标准确率 | LLM 从财报文本提取 5 项指标（营收/净利润/总资产/总负债/净资产），与结构化 ground truth 比对，容差 5% | ≥ 0.6 |
| 风险评级一致性 | 对同一标的运行 3 次 risk_node，统计多数派风险等级占比 | ≥ 0.6 |
| 报告完整性 | 检查报告是否含 5 个必需章节 + 引用 + 数据支撑（CLI 模式无报告，占位 0.5） | ≥ 0.6 |
| 分析师共识对比 | Agent 立场 vs 市场分析师一致评级的偏离度 | ≥ 0.5 |
| 辩论质量 | LLM-as-judge 评审多空辩论的数据支撑/反驳质量/论据多样性（CLI 模式无辩论，占位 0.5） | ≥ 0.6 |

> **注**：报告完整性和辩论质量需要完整流水线输出（final_report + debate_records）。CLI 模式下这两项为占位值 0.5，端到端流水线（`evaluation_node`）会给出真实分数。

## 分析与结论

### 各维度表现

| 维度 | 平均得分 | 通过率 | 分析 |
|------|---------|--------|------|
| 风险评级一致性 | 1.00 | 8/8 | risk_node 基于规则（负债率/净利率/关键词），确定性高，3 次运行结果完全一致 |
| 分析师共识对比 | 0.59 | 8/8 | A 股有 AKShare 分析师评级数据，得分 0.70-0.76；美股/港股暂无分析师评级源，得 0.5 中性分 |
| 财务指标准确率 | 0.35 | 0/8 | LLM 从非结构化财报文本提取数字的准确率有限，5 项指标仅 2 项在 5% 容差内 |
| 报告完整性 | 0.50 | 8/8 | CLI 模式占位，端到端流水线会给出真实分数 |
| 辩论质量 | 0.50 | 8/8 | CLI 模式占位，端到端流水线会给出真实分数 |

### 关键发现

1. **风险评估高度稳定**：8 只股票 3 次运行结果 100% 一致，说明规则+LLM 混合的风控设计有效降低了随机性
2. **财务提取是短板**：LLM 从财报文本提取数字的准确率仅 0.40，后续可改用结构化财报数据直接填充报告，避免 LLM 提取误差
3. **A 股数据最完整**：AKShare 提供财报、估值、分析师评级、新闻全量数据，A 股标的评估维度覆盖最全
4. **港股代码已修复**：`00700.HK` → `0700.HK`（yfinance 4 位格式），修复后港股数据获取正常

### 后续优化方向

- 财务准确率：报告中直接使用结构化 `FinancialStatements` 数据，减少 LLM 提取环节
- 分析师共识：为美股/港股接入 yfinance `recommendations` 接口
- 辩论质量：增加论据交叉引用检查，评估辩论中是否引用了财报/新闻数据
